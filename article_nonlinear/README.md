# article_nonlinear - фигуры для статьи о нелинейном поглощении метаповерхностей

Журнальные рисунки для рукописи «Интенсивностно-зависимое поглощение
метаповерхностей с плазмонными наночастицами золота: нелинейная эффективная
среда» («Оптика и спектроскопия»). Рукопись живёт в вауте Obsidian:
`.../от Лерера/Нелинейность Au/Нелинейные метаповерхности с ПНЧ_рукопись.md`,
там же подрисуночные подписи с расшифровкой номеров кривых.

## Скрипты

```powershell
python article_nonlinear/scripts/make_scheme.py    # fig_scheme: схема метаповерхности (рис. 1)
python article_nonlinear/scripts/make_figures.py   # fig2, fig3, fig3_sc, fig4, fig5
```

Оба скрипта только читают уже посчитанные CSV и ничего не пересчитывают
(кроме длины волны условия Фрёлиха, отмеченной на рис. 2, - той же функцией,
что в `composite_ema/scripts/nonlinear_au_sweep.py`).

## Требования журнала, реализованные в make_figures.py

- подписи осей и весь текст в поле рисунка - только английский;
- кривые пронумерованы, расшифровка - в подписях рукописи, легенды нет;
- без сетки; кривые различаются типом линии, а не цветом;
- каждый рисунок отдельным файлом, PNG (600 dpi) и EPS.

## Соответствие рисунков данным

| Рисунок | Что показывает | Источник данных |
|---|---|---|
| fig_scheme | схема структуры | рисуется кодом |
| fig2 | Re и Im eps_eff композита при I = 0, 5e6, 2e7 W/cm^2 | `composite_ema/results/nonlinear_au_sweep_spectra.csv` |
| fig3 | P(lambda) и dP(lambda) решётки, одномерное приближение, без самосогласования | `grating_2d_rcwa/results/rcwa_nonlinear_au_absorption.csv` |
| fig3_sc | двумерная решётка: dP без самосогласования и самосогласованный, среднее поле в композите | `metasurface_grcwa/results/nonlinear_selfconsistent.csv` |
| fig4 | T_e(t), T_l(t) при импульсе 2 ps | `composite_ema/results/ttm_hot_electron_dynamics.csv` |
| fig5 | наибольшие T_e и T_l в зависимости от длительности импульса | `composite_ema/results/ttm_hot_electron_regimes.csv` |

fig3 и fig3_sc - два варианта рис. 3 рукописи: первый к тексту на расчёте без
самосогласования, второй к варианту на самосогласованном расчёте; выбор -
за соавторами.

Статус: рисунки - отображение данных со статусом исходных подпроектов
(`composite_ema` и `grating_2d_rcwa` - diagnostic, самосогласованный расчёт
`metasurface_grcwa` проверен вторым решателем COMSOL при 530, 550 и 600 нм).
