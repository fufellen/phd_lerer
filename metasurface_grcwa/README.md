# metasurface_grcwa

Расчёты метаповерхностей А.М. Лерера (композит золотых наночастиц в диэлектрике, решётки
цилиндров и столбиков) открытым решателем grcwa - реализацией метода фурье-мод (RCWA) для
двумерно-периодических структур. Закрывают пункты из «Моих предложений» Лерера (письмо
07.07.2026), которые до 09.09.2026 оставались без расчёта. Ход работы и заметки с результатами -
в вауте, папка `от Лерера/` и контрольная точка
`CODEX/Контекст задачи Codex - аудит предложений Лерера и расчёты grcwa 09.09.2026`.

## Состав

- `scripts/lerer_grcwa.py` - общий модуль: материалы (Au по Джонсону-Кристи из `composite_ema`,
  Au по таблице Лерера `data/Au_lerer_nk.txt`, продолжение в ИК моделью Друде), правила смешивания
  (Максвелл-Гарнетт, Бруггеман, MLWA, формула Лерера, первый порядок, Лоренц-Лоренц, несколько
  сортов частиц), сборка слоистой структуры в grcwa (однородные слои, столбики квадратного, круглого и
  эллиптического сечения, конус лестницей слоёв), поглощение по слоям разностью потоков Пойнтинга
  и среднее |E|^2 в композите. Самопроверка: `python scripts/lerer_grcwa.py`.
- `scripts/mixing_rules_on_grating.py` - четыре правила смешивания на решётке цилиндров из входного
  файла письма 19.08.2026 (две таблицы золота), два сорта частиц, ошибка исходной COMPOSITE_3.
- `scripts/mixing_rules_on_article.py` - пять правил смешивания (Максвелл-Гарнетт, Бруггеман, MLWA при
  R = 10 и 15 нм, линейная запись Лерера) на решётке самой статьи о метаповерхностях: цилиндры 400 x 100 нм,
  период 500 нм, слой композита 100 нм, подложка 1,45, Au по Джонсону-Кристи; A, R, T на 400-900 нм,
  сходимость по гармоникам и контроль против собственной двумерной RCWA (`grating_2d_rcwa`) и сверки
  главы 4 диссертации. Итог: в тонкой структуре правило смешивания меняет весь спектр (разброс до 0,75
  при 725 нм), а две реализации метода фурье-мод совпадают до 0,002.
- `scripts/materials_on_pillars.py` - материал наночастиц (Cu, Ag, Au) на исходном столбиковом
  поглотителе по формуле КМ (полный Максвелл-Гарнетт): P, R, T по материальной библиотеке программы
  VIBR_T (`vibr_t/scripts/vibr_materials.py`, Cu ниже 517 нм экстраполирована, как в C-коде) и по
  Джонсону-Кристи; сходимость по гармоникам (`--conv`). Сверка рисунков Лерера к докладу SFM-2026
  (17.09.2026): P совпало в пределах 0,015, положения максимумов R - в пределах 5 нм, уровни - 0,2-2 дБ.
- `scripts/tables_jc_vs_lerer.py` - чувствительность результатов статьи к таблице оптических постоянных:
  материальная библиотека VIBR_T (основная) против Джонсона-Кристи для Au, Ag, Cu - условие Фрёлиха,
  максимумы Im eps_eff по правилам смешивания, полоса Бруггемана, затухание и непрозрачность слоёв,
  столбиковый поглотитель со столбиками и без, сводка и рисунок. Вторая таблица для решёток считается
  теми же скриптами с ключом `--table` (`mixing_rules_on_pillars.py --table jc`,
  `mixing_rules_on_article.py main --table lerer`), результаты - в файлах с суффиксом, основные не
  перезаписываются. Итог (05.10.2026): качественные выводы от таблицы не зависят; граница совпадения
  четырёх правил на столбиках 650 нм по таблице Лерера и 620 нм по Джонсону-Кристи, разброс при 750 нм
  0,554 и 0,581; тонкая структура по таблице Лерера даёт 0,926 при 535 нм (число тезисов Лерера), по
  Джонсону-Кристи 0,924 при 550 нм.
- `scripts/oblique_original.py` - наклонное падение на исходный столбиковый поглотитель (Максвелл-Гарнетт,
  таблица Лерера, 221 гармоника): углы 0, 15, 30, 45, 60 градусов, поляризации p и s, плоскость падения
  вдоль стороны столбика; `--thetas 60` считает выбранные углы в отдельный файл, `--table jc` - вторая
  таблица. Итог (05.10.2026): среднее поглощение на 400-750 нм для неполяризованного света 0,930 при 0,
  0,908 при 30 и 0,828 при 60 градусах; провал на непрозрачном участке полосы ограничен порогом
  отражённого порядка (-1) в воздухе, lambda < d(1 + sin theta); при 750 нм поглощение 0,47-0,57 при всех углах.
- `scripts/pillar_shapes.py` - формы столбиков (квадрат, круг, эллипс, усечённый конус, конус, две
  ступени) для исходной и предложенной конструкций поглотителя; сходимость по ступенькам лестницы.
- `scripts/solar_selective.py` - поглотитель как селективный солнечный поглотитель: alpha_s по
  AM1.5G (pvlib), степень черноты по Планку и Кирхгофу, к.п.д. фототермического преобразования.
- `scripts/ri_sensor_check.py` - поглотитель как рефрактометрический датчик (вода вместо воздуха).
- `scripts/nonlinear_selfconsistent.py` - самосогласованный среднеполевой расчёт нелинейной
  метаповерхности (ветка A, chi^(3) Hache 1988) против расцепленного приближения флагманской фигуры.
- `scripts/plot_*.py` - рисунки по CSV из `results/`.
- `results/` - CSV, сводки и PNG.

## Зависимости

`pip install grcwa pvlib` поверх numpy, scipy, matplotlib; модули `composite_ema/scripts` и
`vibr_t/scripts` этого репозитория.

## Что важно знать о решателе

- grcwa работает в конвенции exp(-i w t), Im eps > 0; таблицы `composite_ema` хранят конвенцию
  Лерера (Im < 0) и сопрягаются в модуле.
- `Volume_integral` grcwa возвращает NaN для однородных слоёв квадратной решётки (вырожденные
  порядки) и занижает поглощение слоя с решёткой на треть; в модуле стоит устойчивая замена
  `Matrix_zintegral`, а поглощение по слоям считается разностью потоков через границы слоя из тех
  же амплитуд, что дают R и T (сумма по слоям равна 1 - R - T до 1e-6).
- Строго нулевой угол падения вырождает матрицу kp; подставляется 1e-4 рад.

## Статус

Все результаты - `diagnostic` до сверки с COMSOL на машине с лицензией; сам решатель на исходной
конструкции поглотителя сверен с COMSOL (расхождение 0,007, заметка «Поглотитель из прямоугольных
столбиков — аналитическое улучшение и проверка RCWA»).
