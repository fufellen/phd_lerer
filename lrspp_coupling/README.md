# lrspp_coupling

Аналитическое воспроизведение двух работ по вводу и выводу излучения в
длиннопробежные плазмонные волноводы (LR-SPP):

- **Park et al., Opt. Commun. 282, 4513 (2009)**, DOI 10.1016/j.optcom.2009.08.038 —
  вертикальный направленный ответвитель между LR-SPP и диэлектрическим волноводом;
- **Park et al., Opt. Express 19, 21605 (2011)**, DOI 10.1364/OE.19.021605 —
  плазмонный преобразователь размера моды ДМД → ДМДМД.

Расчёт полностью аналитический: комплексные собственные моды слоистых структур
методом матрицы переноса, метод эффективного показателя для полосок конечной
ширины, теория связанных волн. Внешних решателей для этого не требуется.
Отдельным скриптом выполняется контрольный полновекторный расчёт открытым
пакетом `femwell` — вместо недоступного COMSOL.

## Структура

- `slabmodes/` — переиспользуемая библиотека:
  - `tmm.py` — ядро: комплексные TM-моды произвольной слоистой структуры,
    восстановление полей, интегралы перекрытия, метрики потерь;
  - `eim.py` — второй шаг метода эффективного показателя (полоска конечной ширины);
  - `cmt.py` — связанные волноводы: извлечение коэффициента связи из супермод,
    перекачка мощности с учётом потерь;
  - `eme.py` — продольный расчёт плавного перехода: адиабатический предел и
    критерий адиабатичности Лава;
  - `materials.py` — оптические постоянные из самих статей.
- `scripts/`
  - `selftest.py` — самопроверка ядра на задачах с известным ответом;
  - `park2009_vertical_coupler.py` — воспроизведение работы 2009 года;
  - `park2011_mode_size_converter.py` — моды, перекрытия и размеры пятна, 2011;
  - `park2011_taper.py` — разложение потерь сужающегося перехода, 2011;
  - `fem_check_femwell.py` — полновекторная проверка ЭДП открытым FEM.
- `results/` — CSV, текстовые сводки и графики.

## Запуск

```powershell
python lrspp_coupling/scripts/selftest.py
python lrspp_coupling/scripts/park2009_vertical_coupler.py
python lrspp_coupling/scripts/park2011_mode_size_converter.py
python lrspp_coupling/scripts/park2011_taper.py
python lrspp_coupling/scripts/fem_check_femwell.py   # требует femwell, gmsh
```

Зависимости основного расчёта — `numpy`, `matplotlib`, опционально `scipy`.
Только для `fem_check_femwell.py` дополнительно нужны `femwell`, `scikit-fem`,
`gmsh`, `shapely` (`pip install femwell`).

## Проверка ядра

`selftest.py` проверяет пять независимых вещей и должен проходить полностью:

1. общая N-слойная невязка совпадает с трёхслойной формулой из
   `edp/metal_strip_w800`, уже сверенной с COMSOL (отличие 3e-15);
2. толстая плёнка даёт ППП одиночной границы с аналитическим
   `n_eff = sqrt(eps_m eps_d / (eps_m + eps_d))`;
3. симметричная плёнка Si|Au|Si воспроизводит корни уравнений Майера (2.29a,b),
   посчитанные независимо бисекцией (совпадение до 9 знаков);
4. симметричный диэлектрический слой совпадает со стандартным трансцендентным
   уравнением (до 10 знаков);
5. восстановленное поле непрерывно на границах, спадает в полупространствах,
   имеет положительный продольный поток мощности, единичное самоперекрытие и
   несопряжённую ортогональность разных мод (2e-15).

## Результаты: Park 2009 — статус `validated`

| Величина | Расчёт | Статья | Отличие |
|---|---:|---:|---|
| n_eff LR-SPP, полоска 6 мкм | 1.430931 | 1.4307 | +0.00023 |
| n_eff диэлектрика, полоска 3 мкм | 1.431255 | 1.4307 | +0.00056 |
| Длина связи при зазоре 5 мкм | 582 мкм | 680 расчёт / 600 измерено | −14 % / −3 % |
| Длина связи при 6 / 8 / 10 мкм | 815 / 1408 / 1956 | 880 / 1480 / 2450 | −7 / −5 / −20 % |
| Предельная перекачка | 94.1 % | 98 % расчёт | −4 п.п. |
| Перекачка с учётом потерь | 89.4 % на 576 мкм | 86 % на 600 мкм измерено | +3.4 п.п. |
| Затухание устройства | 3.81 дБ/см | 4.1 расчёт | −7 % |

Ключевая методическая находка. В планарном пределе волноводы **не
синхронизованы**: их эффективные показатели 1.43215 и 1.43433 расходятся на
2.2e-3, что больше связи. Прямой расчёт планарных супермод поэтому даёт длину
связи 306 мкм — вдвое короче наблюдаемой, потому что расщепление определяется
расстройкой, а не связью. Синхронизм возникает только после сужения полосок по
ширине. Правильная схема: коэффициент связи берётся из точного планарного
расчёта (он задаётся перекрытием хвостов поперёк зазора и от ширины почти не
зависит), а расстройка — из показателей полосок конечной ширины.

Внутренняя проверка связи: подгонка `kappa ~ exp(-gamma s)` даёт
`gamma = 0.349 мкм^-1` против аналитической поперечной постоянной затухания в
обкладке `0.367 мкм^-1`.

Расхождение. Нижняя супермода уходит под показатель обкладки при зазоре менее
3.5 мкм, тогда как статья сообщает отсечку при 4.8 мкм. Гипотеза: метод
эффективного показателя завышает `n_eff` полосок относительно двумерного
векторного расчёта авторов, и запас до линии обкладки получается больше.
Проверяется расчётом методом конечных элементов (не на этом ПК).

## Результаты: Park 2011 — статус `diagnostic`

| Величина | Расчёт | Статья |
|---|---:|---:|
| n_eff рабочей моды ДМД | 1.451180 | 1.450–1.452 |
| n_eff рабочей моды ДМДМД | 1.453407 | 1.450–1.452 |
| n_eff паразитной моды | 1.629788 (планарная) | 1.59–1.613 (конечная ширина) |
| Связь рабочей моды с рабочей | 0.26 дБ | ~0.7 дБ |
| Связь рабочей моды с паразитной | 28 дБ | ~40 дБ |
| Сжатие площади пятна | 40.8 % | 39.4 % |
| Потери ДМД, 3 / 6 мкм | 0.79 / 1.98 дБ/см | 1.89 / 4.38 измерено |
| Потери ДМДМД, 3 мкм | 10.05 дБ/см | 5.01 измерено |

Воспроизведён главный физический аргумент статьи: рабочая мода ДМД почти
целиком переходит в рабочую моду ДМДМД, а паразитная антисимметричная мода
подавлена чётностью — расчёт даёт для неё 81 дБ, то есть связь запрещена
симметрией, и опубликованные 40 дБ являются численным полом, а не физическим
уровнем. Третья мода (плазмон щели, `n = 1.63`) связана слабо, но не запрещена:
28 дБ.

Ограничения, по которым статус `diagnostic`, а не `validated`:

- абсолютные размеры пятна расходятся (18.3 × 8.5 против 11.0 × 10.5 мкм), хотя
  отношение площадей совпадает с точностью 1.4 п.п.; горизонтальный профиль
  метода эффективного показателя слишком широк для слабо ведущей полоски;
- расчётные потери ДМД ниже измеренных в 2.2–2.4 раза. Это ожидаемо: Park 2008
  на той же технологии показал превышение измеренных потерь над расчётными в
  3–4 раза при использовании объёмных постоянных золота;
- потери ДМДМД, наоборот, завышены вдвое относительно измерения, то есть
  отношение потерь двух волноводов воспроизводится плохо.

## Потери сужающегося перехода — статус `diagnostic`

`scripts/park2011_taper.py` раскладывает измеренную зависимость потерь перехода
от его длины на вычислимые слагаемые. Ключ к задаче в том, что вдоль сужения
вертикальная стопка не меняется — меняется только ширина, — поэтому переход
сводится к одномерной горизонтальной задаче, а не к полноценному двумерному EME.

| Длина перехода | Угол | Стык | Поглощение | Сумма | Измерено | Остаток |
|---:|---:|---:|---:|---:|---:|---:|
| 1.5 мкм | 45° | 0.813 | 0.002 | 0.815 | 1.21 | +0.40 |
| 3 мкм | 26.6° | 0.813 | 0.004 | 0.817 | 1.16 | +0.34 |
| 15 мкм | 5.7° | 0.813 | 0.022 | 0.835 | 1.21 | +0.38 |
| 62 мкм | 1.4° | 0.813 | 0.091 | 0.904 | 1.41 | +0.51 |
| 240 мкм | 0.36° | 0.813 | 0.351 | 1.164 | 2.00 | +0.84 |

Что установлено.

**Полку потерь задаёт не сужение, а резкий стык ДМД → ДМДМД при ширине 6 мкм.**
Двумерное перекрытие мод на этом стыке равно 0.829 (по вертикали 0.941, по
горизонтали 0.881), то есть 0.813 дБ — против примерно 0.7 дБ, которые авторы
получили расчётом связи мод в Lumerical. Само сужение при оптимальных 3 мкм
добавляет 0.004 дБ, то есть не делает почти ничего.

**Ни один из изготовленных переходов не является адиабатическим.** По критерию
Лава предельный угол кромки равен 0.047°, потому что горизонтальный контраст
крошечный: `n_eff − n_clad = 1.8e-3`. Даже самый пологий переход из статьи (0.36°)
нарушает критерий в 7.6 раза, а оптимальный — в 565 раз. Отсюда следует, что
удлинять переход бессмысленно: адиабатичности не достичь раньше, чем поглощение
съест выигрыш. Оптимум в 3 мкм — это фактически «сделать переход как можно
короче», и измеренный минимум ровно на это и указывает.

**Рост потерь с длиной поглощением объясняется лишь частично.** Расчётное
поглощение даёт 0.35 дБ на 240 мкм при измеренном росте 0.84 дБ. Остаток ведёт
себя показательно: на длинах до 15 мкм он постоянен (0.34–0.40 дБ) и отвечает
технологии — адгезионный слой, шероховатость, рассовмещение верхней и нижней
полосок золота. Но сверх 15 мкм он растёт, и этот рост пропорционален длине:
он эквивалентен дополнительным ~20 дБ/см в области сужения, то есть тапер теряет
примерно втрое больше прямого волновода той же ширины. Ни статья, ни эта модель
такого канала не объясняют; правдоподобная гипотеза — дефекты кромки металла
вдоль наклонного края после взрывной литографии. Проверяется измерением потерь
прямого волновода с наклонной кромкой.

## Полновекторная проверка: открытый FEM вместо COMSOL

COMSOL недоступен, поэтому контрольный расчёт выполнен открытым пакетом
[femwell](https://github.com/HelgeGehring/femwell) (FEM-решатель мод на
`scikit-fem` и `gmsh`), см. `scripts/fem_check_femwell.py`. Проверяется самое
слабое звено модели — второй шаг метода эффективного показателя.

Существенная тонкость: у полоски 3 мкм мода связана очень слабо, длина спадания
поля в обкладке порядка 13 мкм, поэтому в области 26 мкм FEM выдавал показатель
**ниже** показателя обкладки, то есть моду расчётного ящика, а не волновода.
Область увеличена до 70 мкм; скрипт теперь проверяет связанность найденного
решения и предупреждает, если оно ограничено размером области.

## Что не сделано

Полноценный двумерный EME с базисом излучательных мод здесь не строился: для
разобранных задач он не нужен, поскольку горизонтальная задача одномодовая, а
неадиабатичность оценивается критерием Лава. Он понадобится, если появится
переход с несколькими связанными модами.

Модуль `slabmodes/eme.py` сознательно НЕ выдаёт оценку излучения из дефицита
проекции на связанные моды: для ступенчатой аппроксимации гладкого перехода
такой дефицит убывает при измельчении шага и является артефактом дискретизации,
а не физической величиной.
