# junction_mode_matching

Сшивание мод на соединении встык кремниевого подводящего гребня и плазмонного
фазовращателя Sb₂S₃ | Au 10 нм | Si (1,55 мкм), в обе стороны — диэлектрик → плазмон
и плазмон → диэлектрик, — с проверкой трёхмерной моделью COMSOL 6.2 и вторым открытым
решателем мод. Заметка ваута с разбором результатов: «Переход плазмонного волновода в
диэлектрический — сшивание мод, взаимность и объёмная проверка» (PhD/Scientific_study/…/paper_analysis).

## Метод

Полный набор собственных мод обоих сечений решается открытым пакетом `femwell`
(метод конечных элементов, элементы Неделека первого порядка) на ОДНОЙ сетке: сечение
нарезано на ячейки по всем границам обеих структур, материал назначается ячейке, поэтому
поля обеих сторон живут на одних квадратурных точках и интегралы перекрытия считаются
без интерполяции. На плоскости стыка накладывается непрерывность тангенциальных E и H,
спроецированная на моды с несопряжённым (биортогональным) произведением:

    (U_b + X U_a^{-T} X^T) t = 2 X d,   r = U_a^{-T} X^T t − d,

где `U_a[m,k] = ∫(e_am × h_ak)·z dS`, `X[n,m] = ∫(e_bn × h_am)·z dS`, `d` — единичный вектор
падающей моды, `t`, `r` — амплитуды прошедших и отражённых мод. Второй вариант проекций
(E на h_b, H на e_a) считается рядом; разность вариантов и невязка баланса мощности —
мера усечения базиса. Взаимность проверяется как `t_{a→b} N_b = t_{b→a} N_a`.

Три свойства вывода `femwell.compute_modes`, без учёта которых сшивание даёт мусор
(подробно в `scientific-work/references/open-source-em-solvers.md`):
нормировка на сопряжённую мощность раздувает затухающие моды (перенормировка на
`∫|e_t|² = 1`); главный корень `sqrt(λ)` у части затухающих мод даёт `Im β < 0`
(переключение знака `β` и `H`); комплексные моды-пары имеют нулевую несопряжённую норму
(полные матрицы `U`, не диагонали).

## Структура

- `scripts/mode_matching_junction.py` — сетка, базис мод, сшивание в обе стороны,
  сходимость по числу мод; пишет `mm_results.csv`, `mm_spectrum_<tag>.csv`,
  `mm_fields_<tag>.npz`, журнал `mm_status.txt`.
  Запуск: `python mode_matching_junction.py <scheme> <state> <box> <Nmax> [scale] [n_guess]`,
  где `scheme` ∈ {abrupt, shared450, sync405}, `state` ∈ {a, c}, `box` ∈ {A, B}.
- `scripts/plot_mm.py` — рисунки: сходимость, спектр базиса, структура как решена и поля
  на плоскости стыка. `python plot_mm.py <tag> [папка] [mm_results.csv]`.
- `scripts/philsol_check.py` — второй открытый решатель мод (`philsol`, векторные конечные
  разности) для показателей опорной пары. `python philsol_check.py [dx_nm] [dy_nm]`.
- `scripts/analyze_reverse.py` — модовая передача стыка из S-параметров портов COMSOL в обе
  стороны, отношение назад/вперёд, рисунок профилей мощности.
- `comsol/RunReverse.java` — трёхмерная модель стыка COMSOL 6.2 (половина структуры,
  магнитная стенка, золото как граничное условие перехода, численные порты на обоих торцах),
  возбуждаемая с любого порта: `MR_ONLY`, `MR_DIR=fwd|rev`, `MR_PCM`, `MR_MESH`, `MR_LFEED`,
  `MR_IMAGE`, `MR_SAVE`. `comsol/queue_reverse.sh` — очередь прогонов, по одному `comsolbatch`.
- `results/` — сводные таблицы CSV и рисунки.

## Зависимости

`femwell` (тянет `scikit-fem`, `gmsh`, `shapely`, numpy 2.x), `matplotlib`; для сверки —
`philsol`. COMSOL 6.2 нужен только для `comsol/`.

## Статус

`validated` для схемы sync405 в аморфном состоянии: перекрытие первого порядка 0,9563
воспроизведено, отношение передач назад/вперёд по взаимности `(ρ₂/ρ₁)² = 0,9933`
воспроизведено COMSOL (0,9930 и 0,9934 на двух геометриях), баланс мощности сшивания
сходится до 1e-3. Абсолютная передача сшивания (0,95 ± 0,01 при 200 модах) и COMSOL на
сошедшейся сетке — см. таблицу в заметке ваута; расхождение проекций 1,2 % и разброс по
числу мод ±0,007 — предел метода на этом базисе.
